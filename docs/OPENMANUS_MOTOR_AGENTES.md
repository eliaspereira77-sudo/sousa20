# OPENMANUS - Motor de Agentes Autonomos do SOUSA 2.0

## Principio Mecanico
Se o RUFLO e a Caixa de Transmissao (workflows),
o OPENMANUS e o Braco de Execucao Autonomo (multi-agentes).

Fluxo: SOUSA -> CARDAN_OPENMANUS -> ADAPTADOR -> OPENMANUS (externo)

## Regras
- SOUSA NAO CONTEM o OpenManus.
- Acoplamento via CARDAN, sem dependencia direta.
- Soberania do Fundador absoluta sobre delegacoes.

## Modulos
- SOUSA_OPENMANUS_CARDAN.js (junta de transmissao)
- SOUSA_OPENMANUS_ADAPTER.js (normalizacao de contrato)
