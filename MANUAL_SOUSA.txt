## 1. O QUE É O SOUSA 2.0

O SOUSA 2.0 é um ecossistema multimodular onde cada módulo é um agente
sob comando e coordenação da SOUSA IA. Não é apenas uma fábrica de
ferramentas - é um sistema vivo com memória soberana, agentes autônomos
e capacidade de gerar novas ferramentas sob demanda.

## 4. SOLUÇÃO DE PROBLEMAS COMUNS

### Problema: "git pull" dá conflito
Solução:
  git merge --abort
  git reset --hard origin/main
  git pull origin main

### Problema: "node" não é reconhecido
Solução: Node.js não está instalado ou não está no PATH.
  1. Baixe em: https://nodejs.org/
  2. Instale com opções padrão
  3. Reinicie o PowerShell

### Problema: Pasta travada pelo OneDrive
Solução:
  Stop-Process -Name "OneDrive" -Force
  (faça o que precisa)
  Start-Process "C:\Users\Dionisio Lima\AppData\Local\Microsoft\OneDrive\OneDrive.exe"

### Problema: Quero voltar pro último estado bom
Solução:
  git log --oneline -10  (veja os commits)
  git reset --hard [hash-do-commit]

### Problema: Quero apagar tudo e recomeçar do GitHub
Solução:
  git fetch origin
  git reset --hard origin/main
