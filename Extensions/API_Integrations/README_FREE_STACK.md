# SOUSA 2.0 - Stack Gratuita / Open-Source

Prioridade absoluta: códigos abertos + cotas generosas.

## TTS (Voz Clonada) - Self-Host
- Chatterbox (MIT)
- Qwen3-TTS (Apache 2.0)
- Kokoro-82M (Apache 2.0)
- OpenVoice v2 (MIT)

## LLM
- LiteLLM como gateway
- Groq (cotas generosas)
- OpenRouter modelos :free
- Ollama (local ilimitado)
- Google Gemini (AI Studio)

## Busca
- Tavily (1.000 créditos/mês grátis)
- Fallback: DuckDuckGo

## Como usar
1. Copie .env.example para .env
2. Edite o .env com suas chaves gratuitas
3. pip install -r requirements_free.txt
4. (Opcional) Instale Ollama ou modelos TTS locais

Tudo projetado para não alterar o DNA do SOUSA 2.0.
