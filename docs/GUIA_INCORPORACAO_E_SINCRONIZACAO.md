### Opção 1: Incorporação via Google Apps Script (Recomendada / Mobile-First)
1. Abra o projeto no Google Apps Script (`SOUSA 2.0` / `SOUSA_2.0_PRODUCAO`).
2. Copie os 27 arquivos da pasta `src/` para o seu editor Apps Script (ou sincronize via Clasp / Google Drive).
3. No console do Apps Script, execute uma vez a função de boot:
   `SOUSA_USB_boot()`
4. Pronto! O SOUSA IA estará **acordado, operante e operacional**.

### Opção 2: Testes Rápidos e Comandos via Telegram (SOUSA Connect)
Você pode enviar os seguintes comandos diretamente no bot do Telegram:
- `/status` — Exibe o status da SOUSA IA, USBs operacionais e saúde do sistema.
- `/metricas` — Exibe estatísticas de chamadas, latência e fallbacks acionados.
- `/diagnostico` — Executa a suíte de testes em tempo real e retorna o relatório.
