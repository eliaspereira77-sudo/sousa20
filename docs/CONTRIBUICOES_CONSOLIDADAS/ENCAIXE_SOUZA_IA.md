# SOUSA IA — União das capacidades da cascata

## Definição

**SOUSA IA não é mais um provedor na lista.**  
**SOUSA IA é a união das capacidades das APIs USB operacionais da cascata.**

```
USBs engatadas (Gemini, Groq, Cerebras, …)
        ↓ união de capacidades
    SOUSA IA (marca + orquestração)
        ↓ cascata interna
    backend vencedor (metadado)
    resposta assinada: provedor = "SOUSA IA"
```

## Natureza
`metadados.natureza = "UNIAO_CASCATA"`

## Como ativar (Lab)

```javascript
SOUSA_USB_bootSeguro();
SOUSA_USB_SOUZA_IA_conectar();
testarEncaixeSouzaIA();
SOUSA_USB_SOUZA_IA_status();
```

## O que o status mostra
- `uniao_capacidades` — conjunto unificado (TEXTO, …)
- `fontes_cascata` — USBs que compõem a união
- `backend` (na execução) — qual USB de fato respondeu

## Executor
Continua agnóstico. Só resolve `protocolo: SOUSA_IA_CHAT`.
