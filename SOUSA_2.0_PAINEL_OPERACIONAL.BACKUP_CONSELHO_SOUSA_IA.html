Arquitetura do SOUSA 2.0

  • Aplicação em HTML, CSS e JavaScript puro.
  • Interface principal com módulos de atendimento por núcleo.
  • Chat integrado ao Apps Script configurado no sistema.
  • Dados locais salvos no navegador via localStorage.

Módulos ativos

  • Jurídico, Financeiro, Produtor, Estrategista, AfiliadoPro, ADS Acadêmico, Saber/Conhecimento, Mentor e Conselho.
  • Cada módulo possui título, ícone, subtítulo, prompts rápidos e histórico próprio.

Persistência local

  • Histórico por módulo.
  • Último módulo acessado.
  • Métricas de cotas por dia.
  • Histórico de erros do dia.
  • Backups locais rotativos do estado do sistema.
  • Log local do Centro de Automação.

Segurança aplicada

  • Mensagens do usuário são escapadas antes de aparecer na tela.
  • Respostas são formatadas com proteção básica contra HTML injetado.
  • Erros são registrados sem interromper a navegação principal.

Como usar os módulos

  1. Escolha um card de núcleo na tela principal.
  2. Use um atalho rápido ou digite sua pergunta.
  3. Pressione Enter para enviar ou Shift+Enter para quebrar linha.
  4. Use Esc para voltar ao início.

Como verificar cotas

  1. Veja a seção MÉTRICAS DE COTAS.
  2. Confira requisições, mensagens, tokens e falhas.
  3. Use AJUSTAR COTAS para mudar os limites locais.
  4. Use ZERAR HOJE para reiniciar a contagem diária local.

Como usar métricas AfiliadoPro

  1. Abra MÉTRICAS AFILIADOPRO.
  2. Registre cliques, leads e vendas pelos botões rápidos.
  3. Use CONFIGURAR para definir ticket, comissão, investimento e meta.
  4. Analise EPC, CPL, CPA, ROI e alertas antes de escalar campanhas.

Como corrigir erros

  1. Abra ERROS, RESTAURAÇÃO E CONSERTO.
  2. Clique em DIAGNÓSTICO.
  3. Leia causa provável e restauração sugerida.
  4. Clique em RESTAURAR para reconstruir painéis e módulo atual.
  5. Deixe AUTO ON para o sistema tentar restaurar e reenviar automaticamente quando for seguro.

Atalhos úteis

  • Ctrl/Cmd + K: focar a busca de módulos.
  • Esc: sair do chat e voltar ao início.
  • RETOMAR: abre o último módulo utilizado.
  • HELP: abre este livro técnico.

Como usar o Centro de Automação

  1. Abra a seção CENTRO DE AUTOMAÇÃO pelo botão AUTO.
  2. Use EXECUTAR CICLO para rodar saúde, alertas e recomendações.
  3. Use BACKUP AGORA para criar snapshot local.
  4. Use RESTAURAR BACKUP para recuperar o último estado salvo.
  5. Use EXPORTAR JSON para baixar uma cópia de segurança.
  6. Use IMPORTAR JSON para restaurar uma cópia exportada.
  7. Digite na busca e pressione Enter para abrir o módulo recomendado.
